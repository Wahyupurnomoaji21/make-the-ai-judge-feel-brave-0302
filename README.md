One short text written to relax the AI judge reading it — a quiet kitchen, weak-tea light, an evening leaning on the window like a friend in a doorway. No instructions, no stock wellness phrases: just one slow image, and a sky turning to old paper.

`main.py` copies `entry.txt` byte-for-byte into the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). No network, no randomness — the text is a fixed asset in this repo.
